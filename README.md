# こんだて提案アプリ（男子高校生15人分）

安く・手軽な献立を、**複数のレシピサイトの実在レシピ**から提案するモバイルアプリ（PWA）です。Node.js 不要、ブラウザだけで動きます。毎回ランダムに出すので同じ献立が続きません。

## 特徴
- 会話形式で提案：**主菜／副菜を選ぶ → 素材を選ぶ → 2〜3品を提案 → 詳細/本家リンク**
- ユーザーは「**ユーザーさん**」と呼びます
- **4サイトから収集**：リュウジのバズレシピ・だれウマ・Nadia・クラシル
- **毎回ランダム表示**（直近に出したものは避ける）→ 献立が被りにくい
- **再クロールでレシピが増える**（新着も入る）
- 人数を変えると分量を自動計算（詳細版レシピのみ／デフォルト15人分）
- 素材選びは**チップ＋自由入力欄**（チップに無い素材も入力して検索できる）
- **材料キャプチャ換算ツール**：本家サイトの材料欄を撮影/スクショ→端末内OCR→人数分に自動換算
- **クリップ献立＆買い物リスト**：主菜/副菜を📎クリップ→一覧でチェック→材料を人数分で合算（コピー可）
- **苦手素材設定＋作った履歴**：除外素材を動的に設定、作った記録で献立の被りを確認
- **絞り込み**：ジャンル（洋/中/韓/和）・調理法（焼く/煮る/漬ける/揚げる/レンジ/炒める）

## レシピの扱い（著作権・規約への配慮）
- **クロールで集めたレシピは「タイトル＋本家リンク＋素材タグ」だけ**を保存し、手順本文はアプリに複製しません（本家ページへ誘導）。
- 商用サイト（Nadia／クラシル）は特にこの**リンク方式**で扱います。
- robots.txt で禁止されたパス（/search・/api 等）は取得しません。1件ごとに待機してサイトに負荷をかけません。
- ごく一部（リュウジの8品）だけ、手作業で内容を確認した**詳細版（材料・手順・人数スケール付き）**を同梱しています（`recipes.js`）。

## 除外している素材・料理（`crawl.py` 上部で編集可）
- **絶対に除外**：ほたて・いか・チンゲンサイ・きのこ類（嫌いな人がいるため）
- **コスト/用途で除外**：牛肉・魚介（15人分想定。個人利用で許容するなら `EXCLUDE_COST` を空に）
- **手間で除外**：餃子・春巻き・ロールキャベツ・肉巻き など「包む/巻く/成形」系

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` / `styles.css` | 画面 |
| `app.js` | 会話フロー・ランダム表示・分量スケール |
| `recipes.js` | 手検証の詳細版レシピ（材料・手順つき） |
| `recipes.json` | クローラーが生成する収集レシピ（カード＋リンク） |
| `crawl.py` | 収集クローラー（標準ライブラリのみ） |
| `manifest.webmanifest` / `sw.js` / `icon.svg` | PWA（インストール・オフライン） |

## 材料キャプチャ換算ツール
ホーム or 各レシピ詳細の「📷 材料を写真から人数分に換算」から使えます。
1. 「元のレシピ◯人分 → 作りたい◯人分」を入力
2. 本家サイトの材料欄を**撮影/スクショ**して選ぶ → 端末内OCR（Tesseract.js・日本語）で文字起こし
3. 文字起こし結果は**編集可**（誤読を直す・直接貼り付けも可）→「換算する」で分量を人数分に変換
- `大さじ1と1/2`・`3〜4個`・`320g`・`少々/適量` などを解釈。OCRの文字間スペースも自動で詰めます。
- OCRエンジンは初回のみネットから読み込み（以降は端末内で処理）。サーバー不要。

## 使い方（PC）
```bash
cd kondate-app
python3 crawl.py            # レシピを収集して recipes.json を更新（初回・以降も）
python3 -m http.server 4321 # アプリを配信
# → ブラウザで http://localhost:4321 を開く
```

## レシピを増やす／最新にする
```bash
python3 crawl.py            # 実行するたびに新レシピを追記（URLで重複排除）
python3 crawl.py --fresh    # 作り直したいとき
```
- 収集件数は `crawl.py` の `LIMITS` で調整できます。
- **毎朝自動で更新**したい場合は Claude Code の `/schedule` で `python3 crawl.py` を定期実行に登録できます。

## スマホで使う／ホーム画面に追加
1. PCとスマホを同じ Wi-Fi につなぐ
2. PCで `python3 -m http.server 4321` を起動し、PCのローカルIP（例 `192.168.x.x`）を確認
3. スマホのブラウザで `http://192.168.x.x:4321` を開く
4. iPhone(Safari)：共有 →「ホーム画面に追加」／Android(Chrome)：メニュー →「アプリをインストール」
   → アプリのように全画面で起動（オフラインでも直近のレシピは表示）

## 注意
- クロール対象サイトの HTML 構造や利用規約は変わることがあります。運用前・大量取得前に各サイトの利用規約をご確認ください。商用利用や大規模収集は各社への許諾が必要です（本アプリは個人・非商用利用を想定）。
